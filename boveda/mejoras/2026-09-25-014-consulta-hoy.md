# Endpoint de consulta de gestiones para Hoy

- **Fecha:** 2026-09-25
- **Área:** API / persistencia
- **Estado:** hecha

## Descripción

Se expuso la consulta JPQL que ya existía en `SubtareaRepository` para que el frontend pueda mostrar las gestiones no ejecutadas de la fecha actual. El endpoint recibe el organizador y, opcionalmente, la fecha objetivo; cuando se omite, usa la fecha del huso de Colombia.

## Cambios

- `src/main/java/uv/isj/planificadoreventosbackend/controller/SubtareaController.java` — se agregó `GET /api/subtareas/hoy`.
- `src/main/java/uv/isj/planificadoreventosbackend/service/SubtareaService.java` — se agregó la consulta transaccional de la vista Hoy.
- `src/test/java/uv/isj/planificadoreventosbackend/controller/ApiSprint1Test.java` — se cubrieron pendientes, pospuestas, ejecutadas y otra fecha.
- `README.md` — se actualizó el contrato HTTP y la hoja de ruta.

## Decisiones

- Se reutilizó `SubtareaDTO` para no duplicar el contrato de las subtareas.
- Se excluyen las gestiones `ejecutada`; se mantienen `pendiente` y `pospuesta`.
- La eliminación de eventos ya estaba implementada en `EventoService` y `EventoController`; la base de datos mantiene `ON DELETE CASCADE` en `subtarea.id_evento`.

## Verificación

- `./mvnw test` ✅ — 27 pruebas exitosas.
- La prueba end-to-end contra la base Supabase y el despliegue Render queda pendiente del entorno real.
