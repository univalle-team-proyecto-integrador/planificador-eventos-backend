# Evidencia del tablero Jira — Sprint 1

Esta carpeta guarda la evidencia versionable del tablero Jira del Sprint 1 (tarea de coordinación SCRUM-1-COORD-2). El tablero en sí es externo (Jira Cloud); aquí se conserva la evidencia que permite verificarlo desde el repositorio.

## Contenido esperado

Pendiente de pegar (por alguien con acceso al tablero):

- `sprint-1-tablero.png` — captura del tablero con las tareas y su estado (Sprint 1).
- `sprint-1-backlog-export.csv` (opcional) — exportación del backlog o sprint: ID, resumen, estado, puntos y responsable.

## Checklist para generar la evidencia

1. Abrir el tablero Jira → proyecto «Planificador de Eventos» → Sprint 1.
2. Abrir las columnas o el listado de tareas (Backlog / Board).
3. Capturar pantalla (mantener visibles: nombre del sprint, IDs `SCRUM-*`, estados y puntos).
4. Guardar como `sprint-1-tablero.png` en esta carpeta.
5. Opcional: desde Jira → «Export» (CSV/JSON) de las tareas y guardarla aquí.
6. Registrar el resultado en la mejora bóveda `2026-09-25-019-cierre-brechas-sprint-1.md`.
